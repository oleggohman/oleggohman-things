# cc-things

Claude Code plugin marketplace.

## Install

```
/plugin marketplace add oleggohman/cc-things
/plugin install <plugin>@oleggohman-cc-things
```

## Plugins

| Plugin | What it gives you |
|---|---|
| `mitre-attack` | The [mitre-attack-mcp](https://github.com/oleggohman/mitre-attack-mcp) server (MITRE ATT&CK v20 + ATLAS, run with `uvx`) and the `using-mitre-attack-mcp` skill for mapping incidents and cloud events to techniques, mitigations and detections. Requires `uv`. |
